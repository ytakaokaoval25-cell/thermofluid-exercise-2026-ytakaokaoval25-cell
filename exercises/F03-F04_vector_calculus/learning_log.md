## 証明：curl grad = 0

- 使用した定義：`grad φ = (φ_x, φ_y, φ_z)`と`curl B = (B_{z,y}-B_{y,z}, B_{x,z}-B_{z,x}, B_{y,x}-B_{x,y})`を使った。
- 成分展開：`curl(grad φ) = (φ_{zy}-φ_{yz}, φ_{xz}-φ_{zx}, φ_{yx}-φ_{xy})`となる。
- 混合偏微分を交換した箇所：`φ_{zy}=φ_{yz}`、`φ_{xz}=φ_{zx}`、`φ_{yx}=φ_{xy}`を使った。これには二階偏微分が連続、すなわち`φ`が少なくとも`C²`級であることが必要である。
- 結論：各成分が相殺するので`curl(grad φ) = 0`である。

## 証明：div curl = 0

- 使用した定義：発散と回転の直交座標表示を使った。
- 成分展開：`div(curl A) = (A_{z,yx}-A_{y,zx}) + (A_{x,zy}-A_{z,xy}) + (A_{y,xz}-A_{x,yz})`となる。
- 混合偏微分を交換した箇所：`A_{z,yx}=A_{z,xy}`、`A_{y,zx}=A_{y,xz}`、`A_{x,zy}=A_{x,yz}`を使う。各成分が`C²`級であることが必要である。
- 結論：正負の同じ混合偏微分が対になって相殺するので`div(curl A) = 0`である。

## 証明：積の発散

- 使用した定義：`div(φA) = ∂x(φA_x)+∂y(φA_y)+∂z(φA_z)`を使った。
- 積の微分による成分展開：各項へ積の微分を使うと、`A_x φ_x + A_y φ_y + A_z φ_z + φ(A_{x,x}+A_{y,y}+A_{z,z})`となる。
- 必要な滑らかさと、混合偏微分の交換を使わない理由：一階微分と積の微分だけを使うため`C¹`級で十分で、二階の混合偏微分は現れない。
- 結論：前半は`A・grad φ`、後半は`φ div A`なので、`div(φA) = A・grad φ + φ div A`である。

## 証明：curl curl

- ベクトルLaplacianの定義：`∇²A = (∇²A_x, ∇²A_y, ∇²A_z)`で、各成分に`∂xx+∂yy+∂zz`を適用する。
- 三成分の展開：第1成分は`A_{y,xy}+A_{z,xz}-A_{x,yy}-A_{x,zz}`、第2成分は`A_{x,xy}+A_{z,yz}-A_{y,xx}-A_{y,zz}`、第3成分は`A_{x,xz}+A_{y,yz}-A_{z,xx}-A_{z,yy}`となる。各成分に同じ成分の二階微分を足し引きすると、それぞれ`∂x(div A)-∇²A_x`、`∂y(div A)-∇²A_y`、`∂z(div A)-∇²A_z`になる。
- 混合偏微分を交換した箇所と条件：例えば`A_{y,xy}=A_{y,yx}`、`A_{z,xz}=A_{z,zx}`のように交換する。各成分が少なくとも`C²`級であることが必要である。
- 結論：`curl(curl A) = grad(div A) - ∇²A`である。

## 前進・後退・中心差分

- 3つの差分式：前進差分は`(f(x+h)-f(x))/h`、後退差分は`(f(x)-f(x-h))/h`、中心差分は`(f(x+h)-f(x-h))/(2h)`である。
- 参照する近傍点の違い：前進は現在点と右側、後退は左側と現在点、中心は左右両側を参照する。
- Taylor 展開から予想する収束次数：前進・後退差分の先頭打切り誤差は`O(h)`なので一次、中心差分では偶数次項が相殺し先頭誤差が`O(h²)`なので二次である。

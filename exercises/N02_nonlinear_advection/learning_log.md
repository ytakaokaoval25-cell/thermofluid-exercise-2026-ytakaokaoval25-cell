# N02 学習ログ

## 予想と式・コード

- N01の一定速度移流との違い、左側の広がりと右側の急峻化の予想：N01では全ての値が一定速度 `c=1` で移動する。N02では特性速度 `f'(u)=u` のため、値2の部分は値1の部分より速く進み、左側は広がり、右側は急峻化すると予想した。
- 保存形の流束差分と非保存形の差、式・配列・添字の対応：保存形は `u_new[i] = u_old[i] - dt/dx * (f(u_old[i]) - f(u_old[left]))`、`f(u)=u^2/2` とした。例えば現在値2、左隣1、`dt/dx=1/4`では保存形は13/8、非保存形は3/2で、離散化後の更新値が異なる。標準条件は非負速度なので左側が風上である。
- 固定／周期の格子、周期添字、境界、バッファ交換の説明：固定は端点を含む81点で内部点を更新後、左端を1、右端を左隣とする。周期は同一点の重複を避けるため `[0,2)` の80点とし、先頭の左隣を末尾、その他を `i-1` として全点を更新する。全点で同じ旧時刻を読むため `u_old` と `u_new` を分け、境界適用後に参照を交換する。

## 結果と解釈

- nx、dx、steps、dt、指定CFLと実効最大CFL：固定は `nx=81`、周期は `nx=80`、両方とも `dx=0.025`、`steps=160`、`dt=0.00625`。指定CFLと実効最大CFLはいずれも0.5で、非負場に対する条件 `max_i(abs(u_i))*dt/dx <= 1` の範囲内だった。
- 初期・最終極値、オーバーシュート・アンダーシュート：初期範囲は `[1,2]`。固定の最終範囲は `[1.0, 1.4942095043070338]`、周期は `[1.0000002582164118, 1.8163945680355078]`。両方とも overshoot と undershoot は0だった。有界性は確認できるが、波形精度そのものは保証しない。
- 周期の初期総和・最終総和・符号付き変化量：初期総和101.0、最終総和101.00000000000004、`sum_change=4.263256414560601e-14`。各流束が正負1回ずつ現れる保存形の相殺に対し、Float64の丸め誤差の範囲で保存した。積分量では `dx*sum(u)`を用いる。
- N01との比較に用いた判定量・判定条件と根拠：同じ固定境界、81点、指定CFL 0.5、`t=1`でN01上流差分と比較し、離散L1差 `dx*sum(abs.(u_N02-u_N01))=0.3112563760157095 > 0.2` を確認した。N01は一定速度の平行移動、N02は値に依存する速度による変形であり、どちらにも上流差分の数値拡散がある。
- 図：[固定境界](results/fixed-boundary.png)、[周期境界](results/periodic.png)
- 数値記録：[summary.toml](results/summary.toml)
- 予想との比較、解釈、限界：固定境界では右端から流出し、周期境界では右端を越えた成分が左端へ戻る結果となった。N02の値に依存する輸送による変形と数値拡散によるなまりは区別して解釈した。配布済み `provided_support.jl` の図は `Initial` と `Final` のみを描画し、Web記載の中間時刻曲線を生成しないため、学生編集対象外の同ファイルは変更せず、現状の公式コマンドが生成した3出力を記録した。

- 配布された必須テストの入力・期待値・判断条件を確認し，その意味を説明：流束と周期添字は手計算値と端の折返し、保存形1ステップは非定数配列の期待値と旧配列不変、定数場と境界は流束差0と固定端、標準計算はCFL・有界性・N01と異なる非線形変形を確認する。
- 自作1（周期総和保存）：入力 `[1.0,1.7,1.2,1.9,1.4]`、`dt=0.05`、`dx=1.0`で20ステップ。期待値は最終総和が初期総和と等しいこと。20回の浮動小数演算の蓄積を許容しつつ値の尺度約7に対して十分小さい `atol=1e-12, rtol=0` を用いた。
- 自作1で検出できる誤り／できない誤り：周期端を含む流束の相殺を壊す添字・更新誤りを検出できる。保存していても局所更新や波形精度が正しいとは限らず、固定境界、負速度、他のCFL条件は保証しない。
- 自作2（循環移動と更新の整合）：非対称入力 `[1.0,1.7,1.2,1.9]`、移動量1、`dt=0.05`、`dx=1.0`で、`S(circshift(u,1))`と`circshift(S(u),1)`を比較した。同じ演算の並べ替えに対し丸め誤差を許容する `atol=1e-12, rtol=0` を用いた。
- 自作2で検出できる誤り／できない誤り：先頭の左隣や端だけの不適切な特別扱いを検出できる。1配列・1移動量・1ステップの確認なので、他の配列長・値・複数ステップ・固定境界・CFL超過・精度は保証しない。
